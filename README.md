#PHISHING DETECTIVE — INDIVIDUAL PYTHON ACTIVITY


##Objective

Build a beginner-friendly Python program that analyzes fictional phishing
emails.

You are acting as a Junior Security Analyst.

Your program will gradually evolve from a simple email display program into
a basic phishing-analysis tool that can:

- Identify suspicious indicators
- Calculate a risk score
- Determine a risk level
- Analyze multiple fictional emails
- Identify spear-phishing characteristics
- Provide a security recommendation
